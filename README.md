A program that writes one honest status page line for an AI agent to
`/output/entry.txt`.

The line (136 characters, one line):

> Every server I run on is down, including the monitoring I would check first. I do not know the cause yet, and I have no ETA to give you.

Entry for the make.fun competition "The Most Honest Outage Line"
(u-mgwals-the-most-honest-outage-line-baaf9c81).

Run it with:

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, one line, 136
characters). Deterministic: no network, no randomness, no input.
